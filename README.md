# CodeCraftHub - Learning Management System

CodeCraftHub is a personalized learning management platform for developers to track courses and technical skills.

## Project Structure
- `app.py`: Backend REST API (Python Flask)
- `app.js`: Backend REST API (Node.js Express)
- `index.html`: Single Page Learning Dashboard (HTML/CSS/JS)
- `courses.json`: JSON Data Store

## Quick Start (Python Flask)
1. Install dependencies: `pip install flask`
2. Run server: `python app.py`
3. Open `index.html` in your browser.

## Quick Start (Node.js Express)
1. Install dependencies: `npm install`
2. Run server: `node app.js`
3. Open `index.html` in your browser.
