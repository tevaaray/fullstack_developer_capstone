# Paradise Nursery Shopping Application

A responsive e-commerce web application built with React and Redux Toolkit for browsing and purchasing houseplants.

## Features
- Landing page with company background and "Get Started" call-to-action.
- Product catalog categorized into multiple plant types with thumbnails, names, and prices.
- Redux-powered shopping cart supporting item addition, quantity adjustments, and removal.
- Dynamic navigation bar with real-time cart item counter.
